# Network Packet Analyzer

## CodSoft Cyber Security Internship — Task 1

A Python-based network packet analyzer developed as part of the CodSoft Cyber Security Internship.

## Objective

The objective of this project is to capture and analyze network packets and extract important information such as source IP, destination IP, protocol type, and packet length.

## Features

- Real-time packet capture
- Source IP extraction
- Destination IP extraction
- TCP identification
- UDP identification
- ICMP identification
- Packet length detection
- Packet counting
- Capture summary
- Automatic capture of 50 packets

## Technologies Used

- Python
- Scapy
- TCP/IP networking
